#### 1. Threat Scenario and Context

- **Executive Summary:** An insider threat incident involving employee Torrin on the Forela network was investigated. Initial data loss suspicions yielded minimal evidence in standard storage logs because the user uninstalled unauthorized applications before forensic imaging. However, forensic analysis of the Windows Push Notification database (**wpndatabase.db**) recovered transaction logs generated by the desktop **Slack** client. Analysis of Toast alerts and NotificationHandler records confirmed Torrin contacted an operative from competitor **PrimeTech Innovations** (Cyberjunkie-PrimeTechDev), negotiated the exfiltration of Forela's exploration plans in Angola via an unauthorized channel (forela-secrets-leak), leaked corporate file server credentials, and accepted a **£10,000** bribe after uploading the files to an external Google Drive repository.
    
- **Telemetry Sources and Dataset Contents:** Windows Push Notifications (WPN) database artifacts: wpndatabase.db, wpndatabase.db-wal (Write-Ahead Logging), and wpndatabase.db-shm located in C:\Users\Torrin\AppData\Local\Microsoft\Windows\Notifications\.

``` Yaml
      - '\AppData\Local\slack\'
      - '\slack.exe'
  condition: selection

tags:
  - attack.exfiltration
  - attack.t1567
```

- **False Positive Considerations:** Business units where Slack is an approved enterprise communication channel.
    
- **Tuning:** Filter hosts mapped to authorized IT or engineering divisions.

``` SPL
index=proxy sourcetype="pan:traffic" (dest_host="*drive.google.com*" OR dest_host="*dropbox.com*" OR dest_host="*mega.nz*")
| where bytes_out > 50000000
| stats sum(bytes_out) as total_subido values(dest_host) as destinos by user, src_ip
| table user, src_ip, destinos, total_subido
```

- **False Positive Considerations:** Users legitimately uploading large files to corporate Google Workspace accounts.
    
- **Tuning:** Implement SSL/TLS decryption on proxy connections to enforce corporate tenant restrictions (@forela.co.uk) and block personal accounts.

#### 5. Containment, Remediation, and Hardening Recommendations

1. **Immediate Credential Revocation:** Reset password `Tobdaf8Qip$re@1` across corporate file servers and audit active sessions.
    
2. **Legal and HR Escalation:** Package forensic artifacts for Legal and HR teams to facilitate employment termination and support legal action regarding trade secret theft.
    
3. **Cloud Abuse Takedown Request:** Issue an abuse notification to Google to take down the public Drive folder and preserve account logs.
    
4. **Application Control (WDAC / AppLocker):** Restrict execution of user-space executables managed by the Squirrel installer framework or residing within `%LOCALAPPDATA%`, preventing unauthorized unprivileged software installations.
    
5. **Data Loss Prevention (DLP):** Deploy endpoint DLP policies to monitor and restrict file uploads containing intellectual property (.pdf, .docx, CAD files) to personal cloud storage services.

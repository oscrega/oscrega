#### 1. Threat Scenario and Context

- **Executive Summary:** A series of alerts generated by repeated downloads of potentially unwanted applications (PUAs) onto internal workstation 192.168.1.152 was investigated. Packet capture inspection (network_capture.pcap) revealed a Cryptojacking intrusion. The internal host established outbound HTTP communications with remote server 94.156.177.109:80 to retrieve an initial shell loader (sh). This script profiled the CPU architecture using uname -mp, bypassed noexec-restricted storage partitions, ran a remediation script (clean) to kill rival miners and clean crontabs, and pulled a compiled 64-bit payload (x86_64). The binary was packed with UPX v4.23, staged as the hidden file .redtail, and confirmed as an active variant of the **RedTail** cryptomining botnet (historical sample redtail.cuidado).
    
- **Telemetry Sources and Dataset Contents:** Raw network capture network_capture.pcap (2.1 MB). Reassembled HTTP artifacts: shell scripts (sh, clean) and packed ELF binary (x86_64). Entropy metrics measured with ent and binary unpacking performed via upx.

#### 3. Forensic Investigation Chain and Telemetry Analysis

- **Hunting Hypothesis:** Identify the internal host responsible for the highest volume of outbound HTTP sessions directed toward uncategorized external IP addresses.
    
- **Operational Queries and Commands:**

``` bash
tshark -r network_capture.pcap -q -z conv,ip
tshark -r network_capture.pcap -Y "http.request.method == \"GET\"" -T fields -e frame.time -e ip.src -e ip.dst -e http.host -e http.request.uri
```

- **Technical Breakdown of Evidence:**
    
    - **Compromised Host IP Address:** **192.168.1.152** (generated the largest transfer volume and external session count).
        
    - **Adversary Server IP Address (Payload Delivery):** **94.156.177.109** (TCP port **80**).
        
    - **Initial File Retrieved:** GET request for /sh HTTP/1.1, returning an executable Bash script.

---

- **Hunting Hypothesis:** Deconstruct network retrieval functions and storage policy evasion routines defined within the initial loader.
    
- **Operational Queries and Commands:**

``` bash
tshark -r network_capture.pcap --export-objects "http,./extracted_files"
cat extracted_files/sh
```

- **Technical Breakdown of Evidence:**
    
    - **Download Routine:** Defines function **dlr()**, implementing redundant download mechanisms using wget and curl -O, accompanied by a low-level socket fallback leveraging `/dev/tcp/94.156.177.109/80`.
        
    - **noexec Evasion Checks:** Queries /proc/mounts to identify and avoid mount points configured with the noexec flag.
        
    - **Disk Write Probe:** Validates write access across /tmp, /var/tmp, and /dev/shm by generating temporary files. The second probe file (.testfile2), created via `dd if=/dev/zero of=.testfile2 bs=2M count=1`, is exactly **2 MB** in size.
        
    - **Architecture Profiling:** The script profiles host architecture via:

``` bash
ARCH=$(uname -mp)
```

- **Staged Payload:** Upon matching x86_64/amd64, it calls `dlr x86_64` and renames the payload to **.redtail**.

---

- **Hunting Hypothesis:** Trace the endpoint manipulation routines executed by the second script (clean) across the local filesystem.
    
- **Technical Breakdown of Evidence:**
    
    - Competitor miner elimination to preserve full CPU allocation:

``` bash
systemctl disable c3pool_miner
systemctl stop c3pool_miner
```

- **Scheduled Task Sanitization:** Clears file immutable flags (`chattr -ia`) across `/var/spool/cron/crontabs/*` and `/etc/cron*`, scrubbing entries containing string patterns like wget, curl, base64, or /dev/tcp.

---

- **Hunting Hypothesis:** Identify the runtime packer applied to the binary, calculate unpacked entropy, and extract CTI attribution indicators.
    
- **Operational Queries and Commands:**

``` bash
strings extracted_files/x86_64 | grep -i "upx"
upx -d extracted_files/x86_64 -o ./x86_64_unpacked
ent ./x86_64_unpacked
```

- **Technical Breakdown of Evidence:**
    
    - **Packer Fingerprint:** The binary was packed using **UPX 4.23** (`$Id: UPX 4.23 Copyright (C) 1996-2024 the UPX Team$`).
        
    - **Unpacked Binary Entropy:** **6.488449 bits per byte**, typical for unencrypted native ELF executable sections.
        
    - **CTI Attribution (VirusTotal):** First submitted under the artifact name **redtail.cuidado**.
        
    - **Threat Classification:** **RedTail** mining botnet (incorporates embedded XMRig binaries to mine Monero).

#### 4. Detection Engineering (Alert & Correlation Rules)

``` Suricata
alert http 94.156.177.109 80 -> $HOME_NET any (msg:"SOC - Descarga de Stager RedTail Cryptominer (Funcion dlr)"; flow:from_server,established; file_data; content:"dlr()"; content:"/dev/tcp/94.156.177.109"; fast_pattern; classtype:trojan-activity; sid:20260420; rev:1;)
```

- **False Positive Considerations:** None in legitimate enterprise traffic; combining the `dlr()` routine with a direct call to `/dev/tcp/` toward a public IP is explicitly malicious.
    
- **Tuning:** Deploy across corporate web egress interfaces without filtering by source internal subnet.

``` SPL
index=os_logs sourcetype=auditd (comm="sh" OR comm="bash") (a0="*/.redtail*" OR a1="*/.redtail*" OR a0="*/.testfile*" OR a1="*c3pool_miner*")
| stats count min(_time) as primer_evento max(_time) as ultimo_evento values(comm) as binario values(a1) as argumentos by host, ppid, pid, uid
| convert ctime(primer_evento) ctime(ultimo_evento)
| table primer_evento, ultimo_evento, host, ppid, pid, uid, binario, argumentos, count
```

- **False Positive Considerations:** Enterprise administrative scripts managing temp directories, though hidden dotfiles (.redtail) are anomalous.
    
- **Tuning:** Filter legitimate enterprise monitoring tooling by allowlisting by parent binary hash and UID.

#### 5. Containment, Remediation, and Hardening Recommendations

1. **Host Isolation:** Sever network connectivity for host 192.168.1.152 via EDR network quarantine.
    
2. **Process Termination:** Terminate active processes matching .redtail or outbound Bash socket connections:

``` bash
pkill -9 -f "\.redtail"
```

3. **Perimeter Blocking:** Deploy edge firewall and DNS sinkhole block rules for IP **94.156.177.109**.
    
4. **On-Disk File Removal:** Identify and securely remove all created staging files across `/tmp`, `/var/tmp`, and `/dev/shm`:

``` bash
find / -name ".redtail" -o -name ".testfile*" -exec rm -rf {} +
```

5. **Temporary Storage Mount Hardening (noexec):** Update /etc/fstab to enforce `noexec,nosuid,nodev` mount flags across `/tmp`, `/var/tmp`, and `/dev/shm`, preventing execution of dropped binaries.
    
6. **Restrict Native Shell Network Sockets:** Audit and restrict execution of `/dev/tcp` functionality via AppArmor or SELinux policies in Enforcing mode.
    
7. **Scheduled Task Integrity Auditing:** Deploy auditd configurations to monitor modifications or attribute alterations (`chattr`) targeting `/var/spool/cron/` and `/etc/cron*`.

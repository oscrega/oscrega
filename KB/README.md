
# 📚 Base de Conocimiento (Knowledge Base - KB)

Bienvenido al índice central de la **Base de Conocimiento Técnica**. Este directorio alberga el repositorio completo de auditorías de ciberseguridad ofensiva (*Penetration Testing / Red Team*), investigaciones forenses (*DFIR*) y análisis de datos de seguridad (*SOC / Threat Hunting*) documentados en sintaxis **Markdown nativa (`.md`)**.

A diferencia de los **Informes VIP en PDF** (ubicados en `/reports-pdf/`), la KB está diseñada para la **inspección directa de código, comandos de consola, queries de búsqueda (SPL), artefactos volátiles y playbooks de explotación/remediación**.

---

## 📂 Estructura de Directorios

La base de conocimiento está dividida en tres pilares técnicos clave:

```text
kb/
├── DFIR-reports/       # Análisis de memoria RAM, Triage de Host, Disco y Artefactos Forenses
├── PENTEST-reports/    # Explotación Web, Active Directory, Redes y Elevación de Privilegios
└── SOC-reports/        # PCAP Analysis, Reglas Suricata, IDS/IPS y Queries Splunk (SPL)
